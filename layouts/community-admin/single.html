Supabase Integration & DDL Helper

Proposals submitted by visitors are stored with resilient dual-persistence: automatically synchronized to Supabase table public.author_proposals when accessible, with persistent local browser state ensuring zero loss.

Optional SQL to run in Supabase SQL Editor: 

create table if not exists public.author_proposals (
  id text primary key,
  created_at timestamp with time zone default now(),
  name text not null,
  email text not null,
  title text not null,
  category text,
  outline text not null,
  sample_url text,
  delivery_timeframe text,
  status text default 'pending'
);
alter table public.author_proposals enable row level security;
create policy "Allow anon insert" on public.author_proposals for insert with check (true);
create policy "Allow anon select" on public.author_proposals for select using (true);
create policy "Allow anon update" on public.author_proposals for update using (true);
